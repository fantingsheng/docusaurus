# 插件

## Sass/SCSS 支持

安装插件

```shell
npm install --save docusaurus-plugin-sass sass
```

在配置文件 `docusaurus.config.js` 中增加配置项：

```js
export default {
  // ...
  plugins: ['docusaurus-plugin-sass'],
  // ...
};
```
