# 开始

## 安装

使用 Nest CLI 创建一个新的项目，使用命令：

```shell
$ npm i -g @nestjs/cli
$ nest new project-name
```

或者以脚手架的方式从 Git 仓库中克隆模板：

```shell
$ git clone https://github.com/nestjs/typescript-starter.git project
$ cd project
$ npm install
$ npm run start
```

如果你要安装 JavaScript 版本的起始项目，请将以上地址中的 `typescript-starter.git` 替换为 `javascript-starter.git`。
