# 自定义页面

自定义页面其实就是一个独立的 React 代码实现的界面，我们可以根据需求实现各种功能和样式。

```jsx title="pages/about.js"
function About() {
  return <div>About</div>
}

export default About
```

如果你对设计无感，可以从下面这两个网站找到灵感，它们都是利用 Tailwind CSS 框架实现的原子化的 UI 组件的合集。

- [Flowbite](https://flowbite.com/)
- [Mamba UI](https://mambaui.com/)
