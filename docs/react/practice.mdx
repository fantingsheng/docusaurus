<details>
<summary> 1. 创建一个简单的 JSX 元素 </summary>

```jsx
const JSX = <h1>Hello JSX!</h1>
```

</details>

<details>
<summary> 2. 创建一个复杂的 JSX 元素 </summary>

```jsx
const JSX = (
  <div>
    <h1>Hello JSX!</h1>
    <ul>
      <li>List one</li>
      <li>List two</li>
    </ul>
  </div>
)
```

</details>

<details>
<summary> 3. 如何在 JSX 代码中添加注释 </summary>

```jsx
const JSX = (
  <div>
    <h1>This is a block of JSX</h1>
    {/*
      <p>Here's a subtitle</p>
    */}
  </div>
);
```

</details>
