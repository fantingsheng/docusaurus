## 介绍

要学好一门技术，最好的方式就是**实践**。上面这样一个代码图片生成器，就是当初为了学习 React 技术开发，特地找了一个功能不是很复杂，但是涉及的技术点又不能过于单一，
于是找了这样一个工具型的项目（UI 参照 [ray.so](https://ray.so)），从零实现来检验自己学的知识是否牢固。

简单来讲解下，实现这个项目用到的一些技术点和背后的原理：

- html2canvas
- highlight.js
