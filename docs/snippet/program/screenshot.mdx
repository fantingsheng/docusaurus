截图美化工具，选择指定模型，设置背景，帮你生成多种场景和样式经过美化的图片。

工具访问地址：[https://spacexcode.com/screenshot](https://spacexcode.com/screenshot)

功能和使用场景：

1. 给图片增加背景，预设了纯色背景、渐变色、背景图片，也支持上传自定义的背景图片；
2. 给图片设置边框，套上设备（浏览器、手机、台式电脑、平板电脑、手表、笔记本）的外壳；
3. 设置图片显示在背景区域的位置和尺寸大小；
4. 设置图片的边缘的阴影的深浅；
5. 给背景区域设置高斯模糊和噪点。
