## 介绍

这是为自己制作的一个在线 Web 版的音乐播放器。众所周知，现在市面上的所有的音乐平台都是会员制。而免费的资源却分散在网络上的各个角落，为此，我收集了自己
喜欢的音乐，放到自己的服务器上，并制作了这样一个专属歌单的简单的音乐播放器。


## 实现讲解

播放器虽然简单，但也是五脏俱全，该有的功能一个都没少。比如常见的音乐播放器，都有哪些功能？

- 调节播放进度的进度条
- 调节声音大小的按键
- 暂停/开始播放按键
- 切换下一首/上一首按键
- 查看歌单的界面
