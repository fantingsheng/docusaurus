# 介绍

如果我只能给其他程序员一个建议，那就是编写小的代码块，你要多写**小方法**、**小功能**、**小程序**。

小而美，短而精。健壮的代码是由一个个小的片段组成。

优秀的作家无不是从一个简单优美的句子开始学起，而入门编程也是从输出“Hello World”开始。
