# random

```js
const random = (min, max) => Math.floor(Math.random() * (max - min)) + min;
```

## 介绍

给定一个最大值和最小值，类型为整数，生成这个区间的随机数，且为整数。

## 使用方法

```js
// 生成 [10, 11, 12, 13] 中的任意整数
random(10, 14);

// 生成 1 到 100 中的任意整数，包括 100
random(1, 101);
```
