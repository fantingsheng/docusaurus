## icones

[https://icones.js.org](https://icones.js.org/)

具有搜索功能的图标**资源管理器**，收集了市面上众多常见的图标库，由 [Iconify](https://iconify.design/) 提供支持。

## Iconbuddy

[https://iconbuddy.app](https://iconbuddy.app)

一个很好用的图标搜索引擎，收入了10万+的图标，可以定制和下载每个图标。

<IconbuddyExample />

## Simple Icons

[https://simpleicons.org](https://simpleicons.org)

收集了2770个免费 SVG 格式的国内外著名品牌的图标。提供彩色和黑白两种格式下载。所有图标默认按首字母排序，也提供了搜索功能查找。

<SimpleIconExample />
