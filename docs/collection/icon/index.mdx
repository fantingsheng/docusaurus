# 开源网页图标

import { DevIconExample, HeroiconExample } from './index'

## Devicon

[https://devicon.dev](https://devicon.dev/)

一系列关于编程语言、设计和开发工具的图标，提供了字体格式和 SVG 代码可以直接应用在你的项目中

<DevIconExample />

##  VSCode Icons

[https://github.com/microsoft/vscode-icons#readme](https://github.com/microsoft/vscode-icons#readme)

收藏了 Visual Studio Code 软件上的所有的图标

## Weather Icons

[https://github.com/erikflowers/weather-icons#readme](https://github.com/erikflowers/weather-icons#readme)

222 个与天气相关的主题的字体图标

## heroicons

[https://heroicons.com](https://heroicons.com/)

一个由 Tailwind CSS 开发团队制作的手绘版 SVG 图标的网站

<HeroiconExample />

## Skill Icons

[https://skillicons.dev](https://skillicons.dev/)

在网页中轻松展示你所掌握的技能图标

## icones

[https://icones.js.org](https://icones.js.org/)

具有搜索功能的图标资源管理器，由 Iconify 提供支持

## Iconbuddy

[https://iconbuddy.app](https://iconbuddy.app)

一个很好用的图标搜索引擎，收入了10万+的图标，可以定制和下载每个图标。

## Map Icons

[http://map-icons.com](http://map-icons.com/)

汇集了适用于 Google 地图相关图例和指示或场景标签

## 校徽字体图标

收集了全国200多所高校的校徽，制作成字体图标

[http://xiaohui.lovefc.cn](http://xiaohui.lovefc.cn/)
