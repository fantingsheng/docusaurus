# 项目脚手架

当你学了某项技术，急需实战搭建一个项目玩玩的时候，不知道从哪里开始，需要引入哪些必要的组件的时候。

这时现成的脚手架是你最好的选择。💪🏼

你可以基于脚手架快速生成项目代码，一些基础的配置已经帮你生成，免除你无法开始的尴尬。

这些脚手架都是优秀开发者制作而成，你还可以从中学到很多编程技巧。👨‍💻

### vitesse

Opinionated Vite + Vue Starter Template.

[https://github.com/antfu/vitesse](https://github.com/antfu/vitesse)

### vitesse-nuxt3

Vitesse for Nuxt 3

[https://github.com/antfu/vitesse-nuxt3](https://github.com/antfu/vitesse-nuxt3)

### react-starter-kit

The web's most popular Jamstack front-end template (boilerplate) for building web applications with React.

[https://github.com/kriasoft/react-starter-kit](https://github.com/kriasoft/react-starter-kit)

### electron-react-boilerplate

A Foundation for Scalable Cross-Platform Apps.

[https://github.com/electron-react-boilerplate/electron-react-boilerplate](https://github.com/electron-react-boilerplate/electron-react-boilerplate)

### vitesse-webext

A Vite powered WebExtension (Chrome, FireFox, etc.) starter template.

[https://github.com/antfu/vitesse-webext](https://github.com/antfu/vitesse-webext)

### nextjs-starter

A TypeScript starter for Next.js that includes all you need to build amazing projects.

[https://github.com/chhpt/nextjs-starter](https://github.com/chhpt/nextjs-starter)

### Tailnext

Tailnext is a free and open-source template to make your website using NextJS + Tailwind CSS. 

[https://github.com/onwidget/tailnext](https://github.com/onwidget/tailnext)

### starter-vscode

Starter template for VS Code Extension.

[https://github.com/antfu/starter-vscode](https://github.com/antfu/starter-vscode)

### Landing page boilerplate

A versatile landing page boilerplate, ideal for various projects and marketing campaigns.

[https://github.com/weijunext/landing-page-boilerplate](https://github.com/weijunext/landing-page-boilerplate)
