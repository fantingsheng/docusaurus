# 常见开发解决方案

## 滚动视差效果

滚动视差效果再品牌落地页中十分常见，而纯手写实现又很难，不知从何下手。那我们干脆借助现成的库来实现。

这里推荐两个开源的库

React 环境下

- [React Scroll Parallax](https://github.com/jscottsmith/react-scroll-parallax)

JS 环境实现

- [Locomotive Scroll](https://github.com/locomotivemtl/locomotive-scroll)

## 网页拖拽

出自 [Atlassian](https://atlassian.com/) 团队，支持 Web 几乎所有的主流框架 React、Vue、Svelte、Angular，已在 Jira 和 Confluence 等产品中使用。

- [Pragmatic drag & drop](https://github.com/atlassian/pragmatic-drag-and-drop)

## 调整大小

一个可调整大小的 React 组件。

- [re-resizable](https://github.com/bokuweb/re-resizable)

## 自定义滚动条样式

用于定制原生浏览器滚动条样式的 JS 插件，支持 Web 几乎所有的主流框架 React、Vue、Svelte、Angular

- [OverlayScrollbars](https://github.com/KingSora/OverlayScrollbars)
