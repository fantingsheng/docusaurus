# 富文本和 Markdown 编辑器

## 富文本编辑器

![富文本编辑器](https://i-fanr.oss-cn-hangzhou.aliyuncs.com/1685409532338-fd62d0f7-00bf-4d52-8d8f-3c69c793fce5.png)

### TinyMCE

排名第一的富文本编辑器，支持 React, Vue 和 Angular 等框架

- 开源地址：[https://github.com/tinymce/tinymce](https://github.com/tinymce/tinymce)  
- 官网地址：[https://www.tiny.cloud/](https://www.tiny.cloud/)

### wangEditor

开源 Web 富文本编辑器，支持 JS Vue React

- 开源地址：[https://github.com/wangeditor-team/wangEditor](https://github.com/wangeditor-team/wangEditor)  
- 官网地址：[https://www.wangeditor.com/](https://www.wangeditor.com/)

### Ueditor

由百度前端团队开发所见即所得富文本 web 编辑器，具有轻量，可定制，注重用户体验等特点

- 开源地址：[https://github.com/fex-team/ueditor](https://github.com/fex-team/ueditor)  
- 官网地址：[http://ueditor.baidu.com/](http://ueditor.baidu.com/)

### Quill

强大的富文本编辑器，具有很强的兼容性和可扩展性

- 开源地址：[https://github.com/quilljs/quill](https://github.com/quilljs/quill)  
- 官网地址：[https://quilljs.com/](https://quilljs.com/)

### Draft.js

一款由 Facebook 开源的针对 React 框架开发的富文本编辑器，具有健壮、可扩展和可定制等特点。

- 开源地址：[https://github.com/facebookarchive/draft-js](https://github.com/facebookarchive/draft-js)
- 官网地址：[https://draftjs.org/](https://draftjs.org/)

### CKEditor

强大的富文本编辑器框架，具有模块化架构、现代集成和协作编辑等功能。 使用了 ES6 语法编写，具有出色的 webpack 支持。

同时还提供了与 Angular、React 和 Vue.js 的本地集成。 更重要的是 CKEditor 5 还兼容 Electron 和移动设备（Android、iOS）。

- 开源地址：[https://github.com/ckeditor/ckeditor5](https://github.com/ckeditor/ckeditor5)
- 官网地址：[https://ckeditor.com/ckeditor-5/](https://ckeditor.com/ckeditor-5/)

## Markdown 编辑器

![Markdown 编辑器](https://i-fanr.oss-cn-hangzhou.aliyuncs.com/1685410355011-6482f583-8bdb-41d1-aafd-f5e24ae3344a.png)

### md-editor-v3

Markdown 编辑器 Vue3 版本，使用 jsx 和 TypeSript 语法开发，支持切换主题、prettier 美化文本等

- 开源地址：[https://github.com/imzbf/md-editor-v3](https://github.com/imzbf/md-editor-v3)  
- 官网地址：[https://imzbf.github.io/md-editor-v3/zh-CN/index](https://imzbf.github.io/md-editor-v3/zh-CN/index)

### react-markdown

Markdown component for React

- 开源地址：[https://github.com/remarkjs/react-markdown](https://github.com/remarkjs/react-markdown)  
- 官网地址：[https://remarkjs.github.io/react-markdown/](https://remarkjs.github.io/react-markdown/)
