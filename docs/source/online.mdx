# 在线资源

收集的一些在线的免费资源

## 国内下载

解决一些资源在国内下载慢的问题

### VScode

官网下载页面：[https://code.visualstudio.com/download](https://code.visualstudio.com/download)

如果我们从官网下载跳转过去，最终大概是这么个地址：

```bash
https://az764295.vo.msecnd.net/stable/660393deaaa6d1996740ff4880f1bad43768c814/VSCodeUserSetup-x64-1.80.0.exe
```

下载速度会很慢，这里有个方法，将前面的域名做个替换，改成这个 `https://vscode.cdn.azure.cn`

或者输入一个原始下载地址，我们帮你转换

import { useState }  from 'react';
import { Box, TextField, Button } from '@mui/material';
export function BuildFastUrl () {
  const [link, setLink] = useState('');
  const [helpText, setHelpText] = useState('');
  const [isError, setIsError] = useState(false);
  const [downloadLink, setDownloadLink] = useState('');
  const buildUrl = () => {
    setIsError(false);
    if (!link.length) return;
    if (link.includes('vo.msecnd.net') && link.includes('.exe')) {
      const index = link.indexOf('/stable');
      const newUrl = 'https://vscode.cdn.azure.cn' + link.substring(index, link.length);
      setDownloadLink(newUrl)
    } else {
      setIsError(true);
      setHelpText('这是一个错误的下载链接');
      setDownloadLink('');
    }
  }
  return (
    <div>
      <Box component='div' sx={{ width: 800, maxWidth: '100%', mb: '10px' }}>
        <TextField
          value={link}
          error={isError}
          onChange={e => setLink(e.target.value)}
          label='下载链接'
          helperText={helpText}
          placeholder='https://az764295.vo.msecnd.net/stable/***********.exe'
          size='small'
          fullWidth />
      </Box>
      <Box component='div' sx={{ width: 800, maxWidth: '100%' }}>
        <Button variant='contained' onClick={buildUrl}>生成</Button>
        { downloadLink ? <a href={downloadLink} style={{ marginLeft: '10px'}}>下载</a> : '' }
      </Box>
    </div>
  )
}

### node-sass

`node-sass` 是我们开发中很常见的依赖包，也是安装时间冗长和最常见到报错的依赖。

1. 设置 npm 源为国内镜像

```shell
npm config set registry https://registry.npm.taobao.org

// 或者仅设置 node-sass 下载源为淘宝镜像
npm config set sass-binary-site http://npm.taobao.org/mirrors/node-sass
```

2. 解决二进制文件下载慢

`node-sass` 除了 `npm` 部分的代码，还会下载二进制文件，但是默认源是 github，在国内 github 的访问总是不稳定且很慢。

```shell
set SASS_BINARY_SITE=https://npm.taobao.org/mirrors/node-sass/ && npm install node-sass
```
