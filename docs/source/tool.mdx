## 截图工具

### Snipaste

一款强大的截图工具，基本涵盖截图所需的所有场景。强烈推荐！！！

特性：
- 完全免费，也可以解锁专业版
- 方便对图像进行标注，各种画图工具和模糊处理
- 可以将剪贴板中的内容转化为图片，包括文本、图片、HTML 文本，图片窗口控制，方便取色，贴图分组等功能
- 截图时能自动检测界面元素区域，精准控制鼠标的移动操作，内含取色器，同时支持分屏，历史记录回访

支持平台：
- Windows
- Mac
- Linux（开发中）

官网：[https://zh.snipaste.com/](https://zh.snipaste.com/)  
下载地址：[https://zh.snipaste.com/download.html](https://zh.snipaste.com/download.html)
