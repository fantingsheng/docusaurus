好的工具可以让你工作的效率翻倍，同时开发中优先使用已有的开源方案会让你的项目运行地更稳定。在这里一定能找到令你满意的一款工具。🛠

## 开发工具

### 1. RunJS

JavaScript 运行器的桌面端工具，支持 Windows、macOS、Linux 等主流平台。一边写代码一边看运行效果。还可以导入已发布的包。

官网：[https://runjs.app](https://runjs.app)

### 2. Javascript Playground

网页版在线 JavaScript 运行器，还提供前端学习教程，以实际演练的形式。

地址：[https://playcode.io](https://playcode.io)

### 3. iTerm2

适用于 Mac 的强大的终端工具。它比系统自带的 Terminal 好用得多。有丰富的特色功能，比如快捷键、分屏、定制终端主题颜色等。

- 官网：[https://iterm2.com](https://iterm2.com)
- 下载：[https://iterm2.com/downloads.html](https://iterm2.com/downloads.html)

### 4. 其它

- Npm 包版本查询工具 - [https://semver.npmjs.com](https://semver.npmjs.com)
- Svg 路径编辑器 - [https://github.com/Yqnn/svg-path-editor](https://github.com/Yqnn/svg-path-editor)
- Chrome 历史版本下载 - [https://www.chromedownloads.net](https://www.chromedownloads.net)
- CSS 渐变背景案例 - [https://webgradients.com](https://webgradients.com)

## 截图工具

### 1. Snipaste

一款强大的截图工具，基本涵盖截图所需的所有场景。强烈推荐！！！

特性：
- 完全免费，也可以解锁专业版
- 方便对图像进行标注，各种画图工具和模糊处理
- 可以将剪贴板中的内容转化为图片，包括文本、图片、HTML 文本，图片窗口控制，方便取色，贴图分组等功能
- 截图时能自动检测界面元素区域，精准控制鼠标的移动操作，内含取色器，同时支持分屏，历史记录回访

支持平台：
- Windows
- Mac
- Linux（开发中）

官网：[https://zh.snipaste.com](https://zh.snipaste.com)  
下载地址：[https://zh.snipaste.com/download.html](https://zh.snipaste.com/download.html)
