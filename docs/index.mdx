# 介绍

import { RoughNotation, RoughNotationGroup } from 'react-rough-notation';

这个知识库来自于这<RoughNotation type="underline" color='rgb(77,83,187,0.85)' strokeWidth='2' show={true}>十余年来身为前端</RoughNotation>开发的知识总结，
以及平时收集整理的一些觉得比较好的免费在线的开源的学习资料。

前端知识涉及范围广而且相对比较零散，随着互联网技术和应用的发展，前端行业涉及的知识体系也越来越大庞大，从底层的 JavaScript 语言规范 
<RoughNotation type="highlight" color='rgb(255, 213, 79, 0.5)' animationDelay={800} show={true}>[ECMAScript](http://www.ecmascript.org/)</RoughNotation>，
到类型拓展 
<RoughNotation type="highlight" color='rgb(255, 213, 79, 0.5)' animationDelay={1600} show={true}> [TypeScript](https://www.typescriptlang.org/) </RoughNotation>，
再到应用框架诸如：
<RoughNotation type="highlight" color='rgb(66, 184, 131, 0.4)' animationDelay={1800} show={true}> [Vue](https://vuejs.org/) </RoughNotation>、
<RoughNotation type="highlight" color='rgb(8, 126, 164, 0.4)' animationDelay={2000} show={true}> [React](https://react.dev/) </RoughNotation>、
<RoughNotation type="highlight" color='rgb(255, 62, 0, 0.4)' animationDelay={2200} show={true}> [Svelte](https://www.svelte.cn/) </RoughNotation>，
以及这些技术框架背后涉及的工程化技术，还有最近兴起的 
<RoughNotation type="highlight" color='rgb(255, 213, 79, 0.5)' animationDelay={3200} show={true}> [WebAssembly](https://webassembly.org/)</RoughNotation> 
技术，完全颠覆传统的 Web 开发方式。甚至在后端服务开发上也出现前端开发的身影，从 
<RoughNotation type="highlight" color='rgb(255, 213, 79, 0.5)' animationDelay={4000} show={true}> [Nodejs](https://nodejs.org/) </RoughNotation> 
这些年的应用也看得出来，
<RoughNotation type="highlight" color='rgb(255, 213, 79, 0.5)' animationDelay={4800} show={true}>Serverless</RoughNotation> 
无服务架构也受到越来越多的公司的欢迎。

要想学好前端，绝非易事啊！那么我们从哪该如何开始？

只有先理清前端的 <RoughNotation type="box" animationDelay={5600} color='rgb(244, 67, 54)' show={true}>知识体系</RoughNotation> ，打好底层知识的基础，了解这些应用框架背
后的 <RoughNotation type="circle" color='rgb(244, 67, 54)' animationDelay={6400} show={true}>实现原理</RoughNotation> ，再结合平时开发的大量积累，不断拓宽和深入自己的知识网络，
才能在前端领域站稳脚跟。任凭互联网行业 <RoughNotation type="strike-through" color='rgb(244, 67, 54, 0.65)' animationDelay={7200} show={true}>如何内卷</RoughNotation> ，又有何惧。

最后希望前端的同行，平时多做知识总结，输入过后更要输出，慢慢沉淀出自己的知识库，笔耕不辍。

一些有用的学习资源：

- [FreeFrontend](https://freefrontend.com) - 一些和前端技术（HTML，CSS，JavaScript (jQuery, React, Vue)）相关的免费的资源，包含代码案例，代码演示和文章
- [Deep Dive Into Modern Web Development](https://fullstackopen.com/en/) - 一站式学习 React, Redux, Node.js, MongoDB, GraphQL 以及 TypeScript 全栈技术开发现代 Web 应用
- [Web Development for Beginners](https://microsoft.github.io/Web-Dev-For-Beginners) - 微软官方出品的初学者的 Web 开发课程
- [Learn web development](https://web.dev/learn) - Google 官方 Web 教程
- [Smashing Magazine](https://www.smashingmagazine.com/) - For Web Designers And Developers
