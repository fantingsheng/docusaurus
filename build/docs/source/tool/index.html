常用工具

好的工具可以让你工作的效率翻倍，同时开发中优先使用已有的开源方案会让你的项目运行地更稳定。在这里一定能找到令你满意的一款工具。🛠

开发工具​

1. RunJS​

JavaScript 运行器的桌面端工具，支持 Windows、macOS、Linux 等主流平台。一边写代码一边看运行效果。还可以导入已发布的包。

官网：https://runjs.app

2. Javascript Playground​

网页版在线 JavaScript 运行器，还提供前端学习教程，以实际演练的形式。

地址：https://playcode.io

3. iTerm2​

适用于 Mac 的强大的终端工具。它比系统自带的 Terminal 好用得多。有丰富的特色功能，比如快捷键、分屏、定制终端主题颜色等。

  • 官网：https://iterm2.com
  • 下载：https://iterm2.com/downloads.html

4. 其它​

  • Npm 包版本查询工具 - https://semver.npmjs.com
  • Svg 路径编辑器 - https://github.com/Yqnn/svg-path-editor
  • Chrome 历史版本下载 - https://www.chromedownloads.net
  • CSS 渐变背景案例 - https://webgradients.com

绘图工具​

1. Excalidraw​

手绘效果白板绘图工具，支持在线协同，拥有丰富的素材库，开源，支持自行搭建或魔改。

预览地址：

  • 英文：https://excalidraw.com
  • 中文（支持中文手绘字体）：https://handraw.top

2. Svg drawing​

一个用于轻松绘制草图和重播的画布，可导出 SVG 格式

  • 源码地址：https://github.com/CatsJuice/svg-drawing
  • 演示地址：https://draw.oooo.so

3. 代码图片工具​

  • carbon - https://carbon.now.sh
  • ray.so - Create beautiful images of your code - https://ray.so
  • codeimg - https://codeimg.io

4. 其它​

  • favicon.io - 生成网页图标工具 - https://favicon.io
  • Icon Maker - 软件图标制作工具 - https://icon.ray.so
  • Custom Shape Dividers - 生成特殊形状 SVG 用于图片分隔组合的工具 https://www.shapedivider.app
  • text-to-handwriting - 将文字转成手写版导出图片 - https://github.com/saurabhdaware/text-to-handwriting

截图工具​

1. Snipaste​

一款强大的截图工具，基本涵盖截图所需的所有场景。强烈推荐！！！

特性：

  • 完全免费，也可以解锁专业版
  • 方便对图像进行标注，各种画图工具和模糊处理
  • 可以将剪贴板中的内容转化为图片，包括文本、图片、HTML 文本，图片窗口控制，方便取色，贴图分组等功能
  • 截图时能自动检测界面元素区域，精准控制鼠标的移动操作，内含取色器，同时支持分屏，历史记录回访

支持平台：

  • Windows
  • Mac
  • Linux（开发中）

官网：https://zh.snipaste.com
下载地址：https://zh.snipaste.com/download.html

二维码生成工具​

  • QRBTF - https://qrbtf.com
  • 艺码 - https://yima.me
  • Anthony Fu's QR Toolkit - https://qrcode.antfu.me
  • QR Code generator library - https://www.nayuki.io/page/qr-code-generator-library

统计工具​

1. Shields.io​

在线统计工具，支持多种徽章样式，可以网页图片标签或 Markdown 语法中使用。

https://shields.io

2. Github Star History​

生成 Github 仓库 Star 历史变化趋势图，通过 URL 传入参数：仓库的名称

https://star-history.com

3. Github Commit History​

以图片的格式展示 Github 上用户月度提交频次图表。

https://github.com/2016rshah/githubchart-api
