Devicon​

https://devicon.dev/

一系列关于编程语言、设计和开发工具的图标，提供了字体格式和 SVG 代码可以直接应用在你的项目中

VSCode Icons​

https://github.com/microsoft/vscode-icons#readme

收藏了 Visual Studio Code 软件上的所有的图标

heroicons​

https://heroicons.com/

一个由 Tailwind CSS 开发团队制作的手绘版 SVG 图标的网站

https://skillicons.dev/

在网页中轻松展示你所掌握的技能图标
