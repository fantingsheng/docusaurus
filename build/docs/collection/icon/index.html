开源网页图标

Devicon​

https://devicon.dev

一系列关于编程语言、设计和开发工具的图标，提供了字体格式和 SVG 代码可以直接应用在你的项目中

VSCode Icons​

https://github.com/microsoft/vscode-icons#readme

收藏了 Visual Studio Code 软件上的所有的图标

Weather Icons​

https://github.com/erikflowers/weather-icons#readme

222 个与天气相关的主题的字体图标

heroicons​

https://heroicons.com

一个由 Tailwind CSS 开发团队制作的手绘版 SVG 图标的网站

Skill Icons​

https://skillicons.dev

在网页中轻松展示你所掌握的技能图标

浅色主题

控制每行所占个数

icones​

https://icones.js.org

具有搜索功能的图标资源管理器，收集了市面上众多常见的图标库，由 Iconify 提供支持。

Iconbuddy​

https://iconbuddy.app

一个很好用的图标搜索引擎，收入了10万+的图标，可以定制和下载每个图标。

Carbon(1957)Iconoir(1359)Feather Icons(286)Humbleicons(235)Game Icons(4046)Health Icons(1776)Map Icons(167)Unicons Monochrome(296)Streamline(1000)Weather Icons(215)OpenMoji(4075)Clarity(1103)Gala Icons(51)...

Simple Icons​

https://simpleicons.org

收集了2770个免费 SVG 格式的国内外著名品牌的图标。提供彩色和黑白两种格式下载。所有图标默认按首字母排序，也提供了搜索功能查找。

Map Icons​

http://map-icons.com

汇集了适用于 Google 地图相关图例和指示或场景标签。

ICONO​

纯 CSS 代码实现的图标，并且只使用了一个 <i> 元素标签，然后借助 ::before 和 ::after 伪元素实现。

https://saeedalipoor.github.io/icono

svgl​

漂亮的 SVG 格式的软件产品和公司图标。被整理成分类并提供搜索和下载功能。而且这个网站还提供了 API 服务，不需要授权即可使用

https://svgl.app/api/svgs
# or
https://svgl.app/api/categories

https://svgl.vercel.app

Logo Database​

收集超过3613个全球公司高清Logo的网站，可以通过搜索的方式找到然后用SVG的格式下载，还可以直接拷贝JSX格式的代码。

https://www.fey.com/marketing/logos

Yesicon​

精选全球高品质、开源、免费的矢量图标库
162 个图标库，20 万个精品矢量图标，多种语言跨图标库搜索，丰富的类型及风格筛选，快速自定义图标颜色、尺寸及代码风格，专供开发者和设计师一键复制、下载。

https://yesicon.app

校徽字体图标​

收集了全国200多所高校的校徽，制作成字体图标

http://xiaohui.lovefc.cn

Flag icons​

精心制作的 SVG 格式的所有国家国旗。

https://flagicons.lipis.dev
