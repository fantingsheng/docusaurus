Linux 学习资料

学习 Linux 操作系统绕不开它的一系列命令，记得当年上学的时候，似乎对这种命令式的操作很痴迷。没事就打开黑乎乎的终端，一个命令一个命令地敲，不记得了就去查文档，不厌其烦。

那么如何记住这一大推的命令呢？有点像记英语单词。唯有反复敲，形成肌肉记忆。还有巧用命令查询方法或将命令放在最显眼的地方。
