复制图片在什么场景用到，或者说复制后在哪才能粘贴？

复制后可以粘贴在常用的富文本编辑器中，微信、QQ、钉钉等聊天工具框中。

还有在微博、X、掘金沸点等社交平台输入框中直接粘贴操作，会自动以图片的格式显示，非常方便。

为什么导出的图片和左边展示区域的有差异？

导出图片使用的是 html-to-image 这个库。会有一些支持的不够好的 CSS 属性导致图片略有差异。🥶

上传的图片会泄露隐私吗？

💁‍♂️ 不会，上传的图片只会在浏览器的本地读取，并未上传到云端。该工具类似离线工具，不会收集任何的用户数据。请放心使用。🥰
