## range 

```js
const range = (start, end, step = 1) => {
  let output = [];
  if (typeof end === 'undefined') {
    end = start;
    start = 0;
  }
  for (let i = start; i < end; i += step) {
    output.push(i);
  }
  return output;
};
```

### 介绍

略。。。

### 使用方法

你可以传入一个参数，生成一个从 0 开始的整数数组

```js
// 生成
range(5); // [0, 1, 2, 3, 4]
```

或者传入两个参数

```js
range(5, 10); // [5, 6, 7, 8, 9]
```
