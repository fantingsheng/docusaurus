# 关于本站

本站建立的初衷作为自己前端知识系统结构化总结和平时收集的一些有用的资料，作为备忘。如果这里分享的东西刚好能帮助到访问网站的你，那么它建立的意义又多了一些。

下面是关于本站如何搭建起来的，以及使用到的一些技术和工具，以及部署方案的相关信息。

## 🛠 建站技术

本站由 Facebook 开源的静态网站生成器 [Docusaurus](https://www.docusaurus.cn/) 程序搭建而成。

在基础功能上添加了如下拓展功能：
- 文章底部显示评论功能，基于 [giscus](https://giscus.app/zh-CN) 搭建，参考教程：[How to add Giscus comments to Docusaurus](https://m19v.github.io/blog/how-to-add-giscus-to-docusaurus)
- 文章底部显示微信公众号卡片，版权说明打赏组件，基于 Swizzle 特性对博客页面进行重新定义布局，参考 [Swizzle](https://www.docusaurus.io/zh-CN/docs/swizzling)。
- 首页 Banner 位置增加本地搜索功能，依赖 [docusaurus-lunr-search](https://github.com/praveenn77/docusaurus-lunr-search) 插件。

### 服务器

本站部署在私人阿里云服务器 ECS 上，远程通过 SSH 工具进行管理。Mac 端我使用 [iTerms2](https://iterm2.com)，Windows 上使用 [PuTTY](https://putty.org) ，推荐大家使用。

服务器基础配置：  
- CPU&内存：1核(vCPU) 2 GiB
- 操作系统：CentOS 7.7 64位
- 公网带宽：1 Mbps
- 机房所在地：杭州

### Web 服务器

果断采用轻量、高性能、高并发且安全可靠的 [Nginx](https://nginx.org) 服务器。

### 文件存储

为了缓解服务器压力（内存和速度），文章中的图片和媒体文件存放在阿里云对象存储 OSS 上。图片使用开源自搭建的 Web 工具上传，其它使用 ossbrowser 客户端工具。

### 域名

本站域名 `spacexcode.com` 于 2021年01月购买自[万网](https://wanwang.aliyun.com/)，已备案 [苏ICP备16044739号-3](http://beian.miit.gov.cn)。

这个域名很好记，可以由 `spacex + code` 和 `space + xcode` 组合记忆。很庆幸买到这个域名。

### SSL 证书

为了支持 HTTPS 访问，使用 DigiCert 免费版 SSL 证书，有效期一年，一年后需要重新申请生成新的证书部署到服务器。

因免费证书不支持二级域名，购买了 Rapid 普通版 DV SSL 证书，支持特定单个二级域名 `visitor.spacexcode.com`

### 部署方案

代码托管在 Github 上，为了使得国内服务器上拉代码速度快点，在 Gitee 上做了备份；目前还是采用的本地打包上传，服务端拉取，后面研究自动化部署方案。
